# JavaScript Frameworks Source Code

Source code, demos, labs, and starter projects for a JavaScript Frameworks course focused on modern React development.

Repository:

[js-frameworks-source](https://github.com/ucxinstructor/js-frameworks-source?utm_source=chatgpt.com)

## Course Topics

This repository includes examples and projects covering:

* React fundamentals
* JSX and components
* Props and state
* Event handling
* Conditional rendering
* Lists and dynamic rendering
* Hooks (`useState`, `useEffect`)
* Side effects and cleanup
* Timers and scheduled effects
* Data fetching
* Component composition
* Reusable patterns
* CSS organization
* React tooling with Vite
* State design and management
* Debugging React applications
* Deployment with Vercel

## Running a Project

Most projects use Vite.

Install dependencies:

```bash id="n8e3b0"
npm install
```

Start development server:

```bash id="vxb96y"
npm run dev
```

Create production build:

```bash id="jlwmho"
npm run build
```

Preview production build:

```bash id="c9p0kw"
npm run preview
```
